# Personas

## Privacy-focused local AI user

Owns two to four personal computers, wants local chat and coding help, and does not want to learn model placement. Success means a safe default, a clear capacity summary, and no unexplained network transfer.

## Multi-agent developer

Runs concurrent coding and research jobs. Values one API endpoint, independent routing, reproducible traces, cancellation, and keeping the interactive workstation responsive.

## Homelab operator

Has mixed Windows, Linux, NVIDIA, AMD, CPU-only, and remote hardware. Needs headless installation, quotas, schedules, metrics, logs, explicit runtime compatibility, and manual overrides.

## Small team or lab administrator

Shares trusted workstations across known people. Needs roles, API-key scopes, approval, revocation, audit history, model policy, predictable upgrades, and recoverable backups.

## Node owner

Contributes a laptop or workstation but retains final control over memory, accelerator, power, temperature, bandwidth, schedule, and immediate stop. Cluster administrators may tighten but never silently loosen local policy.

## Contributor and runtime integrator

Needs strict schemas, deterministic tests, narrow ownership, stable adapter contracts, clear capability negotiation, and no need for expensive hardware to run the core test suite.
